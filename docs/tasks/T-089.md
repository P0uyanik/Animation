## Acceptance criteria
1. **New opt-in face version `face_generic/3`** in its own module; `face_generic/1` and `/2` output is unchanged
   (fingerprints, exports and regression renders of both published characters identical to `main`).
2. **Fit, boy first, then girl:** eye opening, lid profile, brow spacing and cheek profile matched to the targets in
   front, 3/4 and side, through neutral, blink and glance. Report eye width and height against the reference
   landmarks (before → after) per view.
3. **Lid shells shortened at the outer corners:** no visible socket rim at 3/4 (measured: lid-shell exposure in the
   build report, and the face 3/4 crop). T-081's smoothing gain is kept (same or better skin smoothness metric).
4. **"Felt eye" shading mode**, opt-in by spec data: matte iris, a lid line, one crisp highlight; the existing glossy
   eye stays the default. Character-agnostic code (no character ids in shared code).
5. **Candidate overrides** per character in this task's own candidate folder (pin `face_generic/3` plus face data);
   no edit to any `*.spec.json` or published version. No version bump (that is T-094 via `tools/version_switch.py`).
6. **Visual deliverable:** per character one cheap first frame (`tools/review/recipe.py preview`) before any long
   render, then one T-087 strict sheet (`recipe.py sheet`, `docs/process/REVIEW_RECIPE.md`) plus a blink/glance
   strip; owner evidence: the sheets, the measurements and fidelity numbers in `docs/evaluation/characters/T-089/`.
7. Tests for the new version (loads, declares its pin, felt-eye mode on/off, lid-corner bound). No test loosened, no
   frozen or published file changed. New tests are listed in the READY report; the Supervisor wires them into the
   gate at merge.
