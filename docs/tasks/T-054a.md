# T-054a: lip-sync toolchain (audio → phonemes → shared visemes), offline tools only
Lane A/C prep · path A · branch `t-054a-codex-lipsync-tools` from `origin/staging` · Implementer: Codex (local)

## Why
Owner approved dialogue + lip sync (roadmap Priority v5, phase 4). This task builds the character-independent data path;
engine playback (blending visemes with emotion/personality in the face layer) is a later task.

## Acceptance criteria
1. `tools/lipsync/`: offline CLI `python tools/lipsync/extract.py --audio line.wav [--text "..."] --out line.visemes.json`
   producing a `plush.visemes/1` track: timed visemes (shared set, e.g. rest, AI, E, O, U, FV, MBP, L, WQ, etc.),
   weights and smoothing/coarticulation, at 24/30 fps. Use an open-source, licence-compatible aligner/recogniser
   (e.g. Rhubarb Lip Sync, MIT, or a forced aligner when text is given); pin version, document licence; no cloud APIs.
2. `content/visemes/shared_visemes.json`: the shared viseme set with descriptions, and a documented mapping to the face
   controls that exist (`docs/evaluation/animation/T-046/README.md` lists them) and to the third character's mouth-shape
   grid (`assets/characters/girl_white_hair_blue_dress/references/uploads/14_face_expression_mouth_shape_grid.webp`).
   Characters lacking a control fall back gracefully (documented).
3. Schema + validator for `plush.visemes/1` and `plush.dialogue/1` (shot-level dialogue lines: speaker, text, audio,
   start time); tests with synthetic audio (e.g. generated tones/espeak if available) checking timing and smoothness.
4. Docs `docs/LIPSYNC.md`. No engine code, no character files.

## Write-set
`tools/lipsync/**`, `content/visemes/**`, `docs/LIPSYNC.md`, `schemas/plush.visemes*.json`, `schemas/plush.dialogue*.json`
(if a schemas folder exists; else inside `tools/lipsync/`), `docs/evaluation/animation/T-054a/**`.
