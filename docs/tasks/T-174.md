## Owner's questions
For walking, running, sitting, standing up, character reactions, interacting with objects, and characters interacting with each other:
1. Which tools, libraries, frameworks, Blender add-ons and ready-made animation systems already exist?
2. Which parts can we reuse or integrate instead of developing them?
3. What have we already implemented that we should keep?
4. Which parts genuinely need custom development?
5. How can we simplify the whole process and cut dev time, token use and unnecessary work?
6. What are the pros and cons of existing solutions vs building our own?
Goal: make animation production easier, faster and more efficient without losing quality.

  rig, content/timing + personality, T-106 acting data, animcheck/motion_checks, grasp/hands (T-117/T-138/T-157), shots e905–e909/e910.

  - other tools and approaches: Cascadeur, video-to-mocap services, text-to-motion/ML generation, motion matching / procedural locomotion, physics (e.g. MuJoCo).
- Rate each option on:
  - fit to chibi/plush proportions (short limbs, big heads);

  instead of requesting them.
