# T-110: Felt surface: one fibre halo for all felt surfaces (round 3)

Implementer: Claude (cloud) · lane D · path B visual · branch `t-110-claude-felt-surface` from `origin/main`.
Owner-approved 2026-11-19 (round 3 start).

## Why
Skin reads plastic, and the felt fuzz differs between the skin, the garments and the hair edges. The references show
one consistent felt surface with a soft fibre halo at silhouettes.

## Acceptance criteria
1. One shared Geometry Nodes fibre halo for felt surfaces (skin edges, garments, hair edges):
   - density, length and colour per material preset (`pipeline/charsys/materials/presets*.json`);
   - opt-in through a new preset/generator version (registry entry, declared at merge);
   - default output byte-identical.
2. **T-110 owns the skin surface:** a less plastic skin (felt micro-surface, roughness and subsurface balance). T-109
   (face round 4) does not touch the skin surface.
3. Evidence:
   - cheap preview first;
   - macro patches (skin, garment, hair edge) and shot-size patches, before/after;
   - one T-087 strict sheet per character against the current versions;
   - render-time cost recorded (Cycles, same settings).
4. Tests for the preset fields and the opt-in path. No test loosened; no frozen or published file changed.
