# T-049: hair approach study (strand groom vs sculpted vs hybrid)
Study · no shared files changed · branch `t-049-claude-hair-study` from `origin/staging`

## Goal
Choose the hair approach for hair v3 (T-044) that best reproduces the owner's felt/plush references for **all**
current and future hairstyles. Owner feedback to solve: today's hair reads as ropes and covers the face.

## Deliverable
1. Prototypes of 3 approaches on **both** characters (boy and girl hairstyles from their references):
   A. strand/lock groom (current `groom/1` direction, improved);
   B. sculpted/felted shell meshes (smooth volumes with felt surface detail, fibres via the shared GN fibres);
   C. hybrid (sculpted base volume + a limited number of locks/strands at edges, fringe and buns).
   Prototype code lives only in `pipeline/charsys/experiments/hair_study/**` (new); no edits to shared generators.
2. Same-camera renders (front, 3/4, back, face close-up) next to the reference images, low samples + OIDN,
   render budget ≤ 24 stills total; plus a 2 s head-turn test per approach for motion/dynamics.
3. Scorecard per approach: visual match (your judgement + `tools/fidelity` hair metrics), face visibility,
   animation/secondary motion, collision behaviour, build and render time, memory, how easily a new hairstyle is
   expressed by spec (reuse), risk. Clear recommendation.
4. Report `docs/evaluation/characters/T-049/README.md` with a contact sheet per character.
