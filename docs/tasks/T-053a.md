# T-053a: reference behaviour and expression analysis (personality from the references)
Study · no code changes · branch `t-053a-claude-reference-behaviour` from `origin/staging`

## Why
Owner decision 2026-11-17: the reference images, character models and videos were designed around each character's
personality (boy: impatient, easily bored; girl: cheerful, intelligent) and are the primary target for appearance,
expressions, movement and animation quality. Personality work must be derived from them, not invented.

## Deliverable
1. **Inventory** of every reference: `docs/references/**` (images, `video_watertable.mp4`, `video_paperboat.mp4`,
   `VIDEO_BENCHMARKS.md`, `VISUAL_TARGET.md`) and each character's `assets/characters/*/references/`. For videos,
   extract frames (ffmpeg, e.g. 2–4 fps plus key moments) into the report folder (small JPEGs, ≤ 120 total).
2. **Per character reference guide** (`docs/characters/<character>/REFERENCE_BEHAVIOUR.md`):
   - appearance cues that carry personality (eye shape and openness, brows, mouth set, head tilt, posture);
   - expression catalogue seen in the references, each with frame/image citations and a description precise
     enough to drive face controls (eyes, lids, brows, mouth corners, jaw, cheeks);
   - body language: posture, weight distribution, hand/finger poses and gestures, idle behaviour;
   - timing: speed of moves, holds, anticipation/overshoot, blink and gaze habits (measure from video where possible:
     frame counts, durations);
   - interaction style (how they handle props, react to the other character);
   - gaps: what the references do not show, and suggestions in the same spirit (clearly marked as extrapolation).
   If a reference video does not show a character, say so; do not attribute behaviour to the wrong character.
3. **Draft personality profiles** `content/personality/<character>.draft.json` plus `content/personality/SCHEMA.md`:
   a character-independent schema (tempo, energy, posture, attention span, boredom/fidget model, gaze habits,
   blink habits, expression bias, gesture set, reaction speed, smile frequency, …) with values derived from step 2
   and a citation per value. Draft only: no engine code reads it yet (T-053 will).
4. **Review checklist** `docs/characters/REVIEW_CHECKLIST.md`: concrete, checkable points per character for
   reviewing animation tasks (T-046, T-045, T-051, T-053, T-054) against the references.
5. Report `docs/evaluation/characters/T-053a/README.md` with a contact sheet per character.

## Write-set
`docs/characters/**`, `content/personality/**` (new), `docs/evaluation/characters/T-053a/**`. Nothing else.
