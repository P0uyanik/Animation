   frame ranges used.
2. **Calibrated timing as data, opt-in first:** a timing profile derived from the table (engine interaction/verb
   durations, holds, settle; per-character tempo in `content/personality/*.json`: boy slower/reluctant, girl quicker
   but with holds; scale-aware where speeds are physical). Existing shots, bakes and regressions are unchanged until
   the owner approves making it the default (then a one-line default switch, separate commit).
3. **animcheck rule** that flags (warning, never a new hard failure, no existing threshold loosened) beats shorter
   than the reference ranges and shots without holds.
4. **Re-timed T-095 e907 exchange** with the profile: before/after video (same camera) and one T-087 strict sheet;
   cheap preview first, Cycles only for the final; heads, cup and contact checks still pass.
5. Tests for the profile loading and the animcheck rule. READY ends with the time-ledger line.
