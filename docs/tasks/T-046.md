# T-046: facial animation (living faces)
Lane C · path A for engine/system code; any change to a character's look = new opt-in version · branch `t-046-claude-facial-animation` from `origin/staging`

## Goal
Owner feedback: "faces are static". Faces must act: expression changes with emotion, blinks with variety,
eye darts and saccades, brow and mouth motion, subtle breathing-linked face motion. Shared system, data-driven.

## Acceptance criteria
1. Engine facial layer drives the existing face controls (shape keys / face bones exported today) from emotions and
   clips: emotion → expression blend with ease in/out (no pops), blink rate and double-blinks varying with emotion,
   saccades and gaze holds, brow raise on attention, mouth corners following emotion.
2. Data in `content/emotions/**` (new `face` sections) and `content/clips/**`; no character names in engine code;
   characters without a control simply skip it.
3. Fix the open gaze test (`look_keeps_gaze` 3.43° vs 0.5° limit) without changing its limit.
4. Tests: per-control continuity (max change per frame), blink timing statistics, emotion transitions, both
   characters + mannequin; plush_tests and CTest fully PASS.
5. Evidence: 4–6 s render of both characters (Cycles, low samples, denoised) showing idle → happy → surprised → sad,
   plus a face contact sheet; compared against `docs/references` faces. Render budget ≤ 2 shot renders.
