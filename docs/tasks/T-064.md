# T-064 (P6): fidelity tool fixes — measurements that reward real visual improvements
Lane A · path A · branch `t-064-claude-fidelity-fixes` from `origin/staging` · from T-063 §3 P6 (owner-approved plan 2026-11-17)

## Why
T-063 found the fidelity score penalises real improvements: T-049 hybrid C (judged best) scores 56.22 vs 64.49 for the
old helmet hair; region IoUs for boots/vest are segmentation artefacts (boots 509 vs 5235 px, vest area 0.29); the
girl's skin_face ΔE00 3.5 misses the visible grey cast. With "drop > 2.0 = FAIL", genuine look improvements trip the
gate. Owner: **visual fidelity to the original references takes priority over numerical scores**; the score must
support, never override, the owner's side-by-side judgement.

## Acceptance criteria
1. Fix region segmentation on renders (garments, boots, vest, hair, skin) so masks match what a person sees; document
   the method; per-region masks saved in reports for inspection.
2. Hair scoring: silhouette/volume/strand-read terms that rank T-049's options the way the visual judgement did
   (C > B > A for boy and girl) — validate on the T-049 renders; no hand-tuning to a single character.
3. Skin and face: a skin-colour metric robust to lighting (luma-matched ΔE plus a grey-cast/chroma term) and a
   face-window metric (eyes/lids/cheeks/mouth regions) that detects the T-063 gaps (lid domes, weak blush).
4. Validation set: for every change, show on existing evidence (T-049 A/B/C, T-055 0.9 vs 0.10, T-058 2.0-dev vs 1.1.0,
   T-063 sheets) that the new score orders versions as the owner/reviewer judged them. Report cases where it still
   disagrees — the owner's judgement wins.
5. Rebaseline `fidelity_baseline.json` scores with the fixed tool for current versions (same renders, new scorer),
   keeping the 2.0-point drop rule; record old vs new scores. Gate and regression tests pass.
6. Reference annotations for the third character's views if needed by the fixed segmentation (data only).
