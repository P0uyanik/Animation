## Scope extension (owner, 2026-11-17): the underlying 3D facial geometry
Owner: "The characters still have significant issues with their facial geometry, especially the chin, jawline, and
overall face shape. Improve the underlying 3D facial geometry to match the original references more accurately."
0. **Head and face geometry fitted to the references** (new opt-in head version in `body_generic`, existing versions
   byte-identical): derive front and side head/face outlines from each character's reference views (front, side, 3/4;
   chin point, jawline, cheek width, forehead, cranium, neck join) and build the head mesh to match them — round
   full cheeks, short soft jaw, small rounded chin, correct chin-to-mouth and mouth-to-eye distances, smooth plush

   outline, front + side) and landmark errors (chin, jaw corners, cheek width, face width/height) before vs after.
   Visual match first; numbers support it.

## Acceptance criteria (new face version; `face_generic/1` unchanged — existing characters byte-identical)
1. **Lids** blended into the skin: no separate pale shells; soft crease shading, a lower lid/lash line, lids using the
   face skin material; blink/squint/happy-closed shapes read as in the references (soft closed-eye arcs, not black
   arcs on pale domes).
2. **Round, full-cheeked faces:** parameters for cheek fullness, face width, lower-face length, chin size, jaw
   roundness; a `soft_smile` rest that lifts cheeks (the girl's closed gentle smile with cheek lift, owner decision).
3. **Brows:** short, soft, felt/painted brows with shape presets (the boy's low flat strokes; the girl's soft arched
   brows; strongly angled in Angry/Sad as in the boy's #28 tiles); placement relative to the fringe so acting is visible.
4. **Eyes:** size/spacing/height parameters wide enough for all three characters (third character's large, wide-set
   eyes); iris colour per spec (girl brown, boy dark brown, third character blue).
5. **Mouth:** fuller, wider lips option (girl ref_34), small pout (boy), parted-lips rest variant (third character
   while watching).
6. Candidate specs (inside this task's evidence folder) for boy 2.0-dev, girl next version and a third-character
   head-only test, each rendered next to its references: front, 3/4 face close-ups and the expression set (neutral,
   happy, sad, surprised, angry, bored/sleepy). ≤ 24 stills, Cycles low samples + OIDN. Honest list of remaining
   differences; judge visually against the references first, scores second.
7. Face controls stay compatible with the T-046 face layer and T-058's per-side controls; tests; full gate PASS.
