# T-113: Expression library expansion with per-character sets (round 3)

Implementer: Claude (cloud) · lane C · path B visual · branch `t-113-claude-expressions` from `origin/integration/t-109`
(input SHA in the task prompt). Owner-approved 2026-11-19 (round 3: "T-113 expression library expansion (incl.
per-character sets from T-106) after T-109").

## Why
- The shared emotion library (`content/emotions/`) has 8 emotions; per-character sets exist only as T-097's
  first files (boy_interested, girl_wonder, girl_delighted).
- T-106 measured expression changes, glances and blinks per character in the reference videos
  (`docs/evaluation/animation/T-106/`). No face library preset is calibrated against those measurements yet.
- T-109 added SmileOpen and Pout (`pipeline/charsys/face_library/expressions.json`), but no emotion uses them yet.
  e908 still calls smile.
- Pre-existing defect (T-109 README §8a): in Smile and Laugh, the closed lids show as pale domes on both current
  versions.

## Acceptance criteria
1. Per-character expression sets as data:
   - boy: sleepy, reluctant, unimpressed, interested and the like;
   - girl: delighted, wonder, eager, shy and the like;
   - each calibrated against the T-106 measurements, with the frame ranges cited.
   They are built from face library presets plus emotion files (`content/emotions/<char>_*.emotion.json`). The shared
   library stays exactly 8 (test_emotions.cpp).
2. Emotions that the references show with an open smile use SmileOpen. Pout is used where the reference sulks.
3. Fix the pale-dome closed lids in Smile/Laugh: closed lids follow the eyeball surface, in both versions'
   builds and the candidates. Opt-in where geometry changes; default output identical, or the change listed with
   evidence.
4. Evidence:
   - a cheap preview first;
   - one Cycles expression sheet per character: each expression next to the closest reference frame;
   - e908 acting frames re-rendered with the new sets.
5. Tests: preset and emotion files validate; per-character sets are listed in a test; lid-dome check (closed lid
   within N mm of the eyeball surface). No test loosened.
