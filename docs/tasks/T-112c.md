## Acceptance criteria
1. The verb expander takes each grasp's hand shape from the T-051 table (by the site's `hand_shape` name), replacing
   T-112a/b's inline defaults. Each value must come out identical to the inline one where the two coincide; list any
   difference with the reason.
2. Box-face sites key `hand.<s>.graspFace` from the affordance (`graspShape`), so per-finger grasps work on the
   felt_tray box.
3. e907 `s010_verbs`: the T-051 measurements (tip gap, contacts in band, thumb opposed, wrist/palm unchanged) hold
   for both characters. One cheap preview, then one Cycles strict sheet of the shared hold.
4. Golden bake hashes (`tests/golden/`) are unchanged for non-verb scenes. Verb scenes may change only where
   criteria 1–2 say, documented.
5. Tests for 1–2; no test loosened.
