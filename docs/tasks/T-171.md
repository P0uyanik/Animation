2. Pre-shaping during the reach: the hand opens and shapes toward the object before contact, timed against the
   reference videos.
3. Finger-by-finger close, staggered rather than all at once, with soft contact: no penetration, small settle, no pop.
   Report per-finger gaps and the penetration check, as in T-157.
4. Everything is a candidate / opt-in. The default path is byte-identical, goldens are unchanged and released versions are
   untouched. New guarded features need the owner's approval via the Supervisor; none is assumed.

   the owner's decision.
6. Evidence for the owner: strict sheets + hand close-ups at shot size and short clips (e910 setup and one reference-matched
   reach), before/after vs current.
