## Acceptance criteria
1. **Importer** `pipeline/clips/import_bvh.py`, built on the existing `pipeline/clips/retarget.py` / `clip_tools.py`
   (T-174 test `docs/evaluation/animation/T-174/test/bvh_retarget_test.py`). It:
   - adds the CMU role map;
   - folds the extra spine and neck joints;
   - resamples to 24 fps;
   - writes licence + attribution into each clip;
   - auto-fills `contacts.foot_plant`.
   Tests: round-trip and 0° limb-direction error.
2. **Starter clips** in `content/clips/mocap/` (CMU only, attribution file alongside): at least a walk cycle and a
   sit-down + stand-up. Turn/run/idle only if cheap.
3. **Foot-lock + chibi style filter**:
   - a two-bone leg IK pin on `foot_plant` frames;
   - a per-clip `style` block (lean, stride/root scale by leg ratio, arm swing, timing toward `content/timing`) read by
     `clip_layers`.
   Accept on motion_checks: foot slide ≤ 3 mm while planted, no popping. Report floating and slide numbers before/after.
4. **Opt-in only.** Existing shots and defaults are byte-identical and goldens are unchanged. Character geometry, looks and
   the rig itself are NOT changed; if a rig change seems needed, report BLOCKED first.
5. **First delivery for owner style review** (CHECKPOINT, then STOP before wider use):
   - a walk and a sit/stand clip on the boy and the auburn girl (and the third girl if possible);
   - feet-planted check numbers;
   - short clips (review profile is fine) plus one strict sheet per character;
   - all under `docs/evaluation/animation/T-175/`.
