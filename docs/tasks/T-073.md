# T-073: render benchmark on the owner's PC (CPU and, if present, GPU)
Implementer: Codex (owner PC) · study · branch `t-073-codex-pc-render-bench` from `origin/staging`

## Why
T-050 estimated render costs without a GPU; the owner cannot rent one. Real numbers from the owner's PC decide how
to render the benchmark scene and episodes (owner decision: CPU-only planning unless local hardware helps).

## Acceptance criteria
1. Report the PC's CPU, RAM, GPU (model, VRAM, driver) — no personal data, no files outside the work folder on C:.
2. With the repo's pinned Blender/bpy, render T-050's probe settings (640×360 16 spp; 1080p 64 and 128 spp + OIDN)
   on CPU and, if a supported GPU exists, CUDA/OptiX/HIP; ≥ 3 frames each; report s/frame and the episode estimate
   with T-050's model (`docs/evaluation/render/T-050/cost_model.py`).
3. Recommendation: what to render on the PC vs cloud containers. Report `docs/evaluation/render/T-073/README.md`.
4. Write nothing to D:; delete only your own temporary files.
