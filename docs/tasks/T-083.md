## Method
1. Extract frames (all frames of short clips; ≥ 2 fps for long ones). Match comparable moments between references and
   ours (same view, similar pose/action/framing).
2. Build side-by-side contact sheets: reference | ours (newest) | ours (previous), per category below.
3. Measure where it is meaningful, on matched crops: colour difference (ΔE2000 of skin, hair, main garment, background),
   silhouette/proportion ratios (head:body, eye size/spacing, hair volume), texture/softness (high-frequency energy,
   noise), timing (holds, spacing, number of frames per action), and the existing fidelity score per character.
4. Judge visually, citing frames: every claim cites a reference timestamp/frame and our file + frame.
