## Acceptance criteria
1. **Set as data** in `content/sets/` (new): a minimal procedural water-table corner (table, back wall with a window,
   two or three background shapes), a light rig (window key, rim on the wool, fill) and one camera preset with soft
   depth of field, all in one data file; a small tool applies a set to a shot scene (objects, lights, camera) and
   writes a new shot file. No new renderer features: if `shot_render.py` cannot express something, record it as a
   finding.
2. **Render the T-095 exchange still** (the shared-cup frame) in the grey studio and in the set, same characters
   (`current` cast), same frame, one comparison sheet with the references (PB f12/f231, WT f24).
3. **Measure seconds per frame** at review settings and at final settings (resolution, samples, denoise recorded,
   machine and Blender version recorded) for studio and set; project the cost per minute of animation (24 fps).
4. **Recommendation** (one page): for or against a full environment phase, with the measured costs and what the set
   adds visibly. The full environment phase stays out of scope.
5. One cheap first frame (low samples) before the long renders; owner evidence in `docs/evaluation/rendering/T-098L/`.
6. Tests for the set tool (schema validation, deterministic output, refuses unknown keys). No test loosened, no frozen
   or published file changed; existing shots unchanged.
