# T-025: garment/1 robustness, shared fixes (owner-approved 2026-11-16; start after T-024)

Rule: every fix lives in the shared `garment/1` system (`pipeline/charsys/garments/`). Nothing per character, and no
character names. Existing outputs stay unaffected: the boy byte-identical, the girl's T-024 renders unchanged except
where a listed fix applies (show a before/after).

1. Dress armholes: derive the armhole shape and size from body measurements (arm root circumference and shoulder
   width) so sleeveless and short-sleeve garments fit any body with no gaps or poke-through.
2. Skin-contact detection: a crease-robust inside/outside test that tells real poke-through from touching skin in
   folds (armpit, crotch, elbow); one documented tolerance.
3. Proportion-relative distances: every offset, ease, mask margin and collision distance scales with local body
   measures (limb thickness, torso depth, head size) instead of fixed millimetres. The defaults must reproduce
   today's results on the current bodies.
4. A second synthetic test body in `garment_generic_test`, built with `body_generic` at extreme but plausible
   proportions: a larger head, shorter and thicker limbs, a rounder torso. Both outfits must pass clearance in the
   rest pose and all test poses (rest pose + the 6 clip poses + sit_down).
5. The pose list comes automatically from `content/clips/*.clip.json` (sampled extremes), so new clips become new
   test cases.

Acceptance:
- `garment_generic_test` PASS on both synthetic bodies.
- verify_charsys and test_export_engine PASS.
- The boy is byte-identical; the girl's before/after is documented.
- No test thresholds loosened.

Evidence in `docs/evaluation/characters/T-025/`: both test bodies in both outfits, the worst poses, and the clearance
table.
