# T-061: animation principles pass — slow-in/slow-out, arcs, spacing metrics
Lane C · path A (shared engine/tools; visible motion improvement, owner reviews before/after) · branch `t-061-claude-animation-principles` from `origin/staging`

## Why
Owner-shared external critique (AnimLog, 2026-11-17) on the T-045 wave, verified by the Supervisor:
1. **Timing & spacing:** the lift out of rest has constant speed — clip layers blended in over 4 frames and played at
   speed 1.5 squeeze out the clip's own slow-in/slow-out.
2. **Arcs:** the hand travels in a near-straight path during the raise (partial-weight slerp toward the rest pose,
   compressed timing).
3. **Overlap:** hair and hoodie strings static (data: T-044 hair chains, T-058 hoodie; this task adds engine support
   for accessory chains if missing).
References remain the primary target (`docs/characters/*/REFERENCE_BEHAVIOUR.md`, timing measured there).

## Acceptance criteria
1. **Slow-in/slow-out that survives retiming and blending:** clip layers ease their entry/exit with a proper ease
   curve and a minimum blend duration derived from the motion amplitude (not a fixed 4 frames); speeding a clip up
   retimes it with an ease-preserving time warp (anticipation/extremes keep their spacing) instead of a linear scale.
   Same for IK-driven gestures (reach/point/wave) in `actions.cpp`.
2. **Arcs:** gesture paths follow shoulder/elbow arcs: blending toward/from rest happens in joint space with
   per-joint easing and timing offsets (shoulder leads, elbow/wrist follow = successive breaking), plus automatic
   breakdown poses where the wrist path would be near-linear. Interaction contacts stay ≤ 5 mm.
3. **Measurable:** a tool `tools/animcheck/` reporting per gesture (from a bake): speed profile (ease-in/out ratio:
   speed in first/last 20 % vs peak), wrist-path arc deviation, max per-frame step, overshoot/settle. Added to the gate
   (fast, on the regression shots) with thresholds documented and justified; never loosened later.
4. **Accessory secondary motion:** spring chains can be attached to garment/accessory parts (drawstrings, straps,
   bow tails) through data, reusing the T-021 spring-chain system; documented for T-044/T-058 to use.
5. Evidence: the same wave shot as T-045 (layer on) before/after, plus speed and wrist-path plots; ≤ 2 renders.
   All existing tests unchanged and passing; full gate PASS.
