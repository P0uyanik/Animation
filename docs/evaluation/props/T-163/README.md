12 new props (`content/assets/felt_*.asset.json`) + the existing `felt_cup` = 13. Generated by `tests/props/make_props.py`
(`--check` verifies the files). Conventions as `felt_cup` / `felt_tray` (T-111/T-112): base-origin cylinders, centred
spheres/boxes, sockets `grip*`/`place`/`contact`, `plush.affordances` v1, rigid, material preset `felt` only.

## Tests (new, standalone: `tests/props/`; `tests/CMakeLists.txt` is outside the write-set)
`cmake -S tests/props -B build/props -G Ninja -DPLUSH_BUILD_STUDIO=OFF && cmake --build build/props && build/props/plush_prop_tests`
- schema/conventions for all 12; library size 13 (10–15);
- verb test per prop: pick_up + carry + place through the real verb expander on the boy and the girl skeletons
  (verb constraints enforced on load; palm on site ≤1.5 mm, tilt ≤ `max_tilt_deg`, lifted, placed on target ≤1.5 mm);
  box_lid is lifted off the box and put aside ("open"); box and basket use both hands;
- lid seat geometry; handover lists on one-hand props.
Result: 3 test cases, 593 assertions, all passed (palm error < 0.001 mm, tilt 0°).

`contact_sheet.png` is a **schematic** drawn from the asset data (front view, one scale), not a render.

## Not tested / limitations
- No pass (two-character handover) or finger-contact (`fingers`) test; no Blender render of the props.
- `toy`/`basket` are primitives only (no ears/handle geometry); `book` has no open state (verbs reject non-rigid deform).
- Existing `felt_cup` collision capsule is not base-aligned (unchanged; visible on the sheet).
