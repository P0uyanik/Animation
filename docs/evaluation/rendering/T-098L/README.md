## What the set adds visibly (sheet)
- Window and place: a bright back window with mullions, cream walls, warm wood floor, rug, a water table, a shelf
  with two bins, a drawing. The frame now reads as "a classroom corner" instead of a grey cyclorama.
- Light: warm window key from frame left, a rim on the wool (top of the boy's hair, the girl's bun and right hair edge
  catch light; compare the final 1920 frames), cool low fill; the palette moves towards the references' warm interior.
- Focus: f/1.2 focused at the camera target keeps both faces and the cup sharp and softens the back wall and shelf.
- Characters, pose, cup, framing: unchanged.

Not achieved vs the references (PB f12, WT f24): the set looks like painted plaster boxes, not wood and toys: no wood
grain, no clutter, no gloss on the water, no window view. The faces are slightly lighter and flatter than in the
studio (more bounce in a closed cream room); the rim is subtler than in the references. These follow from the findings
below, not from the set data.

## Findings: what shot_render.py cannot express (no renderer change made)
1. **Box objects get only a base colour**; roughness is fixed at 0.9 and the scene material's roughness/specular are
   ignored (`setup_world`). No textures, no material presets for set objects (props have presets, boxes do not): wood,
   water and paper all look matte plaster.
2. **No emissive surface or backdrop**: a window can only show the world sky colour. On an open set the same sky
   floods the whole scene as fill (first cheap trial: washed out). Workaround used: a closed room (ceiling, front and
   side walls) so the sky enters only through the two windows; this costs bounce time (part of the +19 %).
3. **Geometry is boxes only** for set objects (no cylinders, meshes or assets as static dressing); the T-022 prop
   primitives exist but only for baked props.
4. **No light linking or camera/shadow visibility control**: the rim also lights the set; it cannot be limited to the
   wool. Rect lights are invisible to the camera (fine here).
5. **Sky is one uniform colour** (no HDRI, no outside view).
6. Works as data today: rect/sun/sky lights, camera depth of field (fStop, focusDistance), exposure.

## Recommendation (one page)
**Against a full environment phase now; for two small, separate steps first.**

Why: the set as data works and costs little (+19–22 % per frame), and it does move the frame towards the references
(window key, rim, focus, warm place). But a full environment phase would be built on a renderer path that cannot yet
make a set look like the references (findings 1–3: no materials, no emission, boxes only), and on a render budget we
cannot afford: at final settings one minute of animation is ~16–20 machine-days on this 4-core CPU, an episode
~36–44 days, with or without a set. More set detail would only add to that.

Suggested order (each its own task, for the Supervisor to decide):
1. **Render budget first** (the T-074 measurement continued): GPU or a bigger CPU machine, final samples vs denoise
   (e.g. 32–64 spp + OIDN), EEVEE for review, per-frame variance over a whole shot. Target: a measured final cost per
   minute that fits the production plan.
2. **A narrow shot_render extension** (Blender pipeline only, TD-43 respected): material presets for set boxes from
   the shared material library (wood, painted wall, water), an emissive backdrop or window card, and static asset
   dressing (reuse prop primitives/meshes). Re-render this same f48 with the same set file to judge it.
3. Only then decide on a full environment phase (layouts, dressing libraries, per-episode sets).
