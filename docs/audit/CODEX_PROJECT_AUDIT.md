- **Modelling and facial rigging.** Use matched orthographic overlays and Blender's existing shape keys for the jaw, smile, blink and corrective lids. The expression library already supplies the corresponding controls and the production bake maps them. - **Groom and shading.** Reuse the hybrid felt volumes and Geometry Nodes surface-fibre group. Spend the first experiment on the camera-visible action, and use a corrective deformation for a repeatable local cloth defect if weighting cannot solve it.
